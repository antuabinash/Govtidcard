ଦ୍ବିଘାତ ସମୀକରଣ Ex-2(b)

ଦ୍ବିଘାତ ସମୀକରଣ Ex-2(b) – Study Material Class 10 ବୀଜଗଣିତ

ପାଟୀଗାଣିତିକ ପ୍ରଶ୍ନ ପାଇଁ ଆବଶ୍ୟକୀୟ ସୂତ୍ର (Formulas for Word Problems)

🔢 ୧. ସଂଖ୍ୟା ସମ୍ବନ୍ଧୀୟ (Number Problems):

  • କ୍ରମିକ ଗଣନ ସଂଖ୍ୟା (Consecutive Integers): ଯଦି ପ୍ରଥମ ସଂଖ୍ୟାଟି xx ହୁଏ, ତେବେ ପରବର୍ତ୍ତୀ କ୍ରମିକ ସଂଖ୍ୟାଗୁଡ଼ିକ ହେବେ: x,x+1,x+2,…x, x+1, x+2, \dots

  • କ୍ରମିକ ଯୁଗ୍ମ କିମ୍ବା ଅଯୁଗ୍ମ ସଂଖ୍ୟା (Consecutive Even/Odd Integers): ଯଦି ପ୍ରଥମ ସଂଖ୍ୟାଟି xx ହୁଏ, ତେବେ ପରବର୍ତ୍ତୀ କ୍ରମିକ ଯୁଗ୍ମ/ଅଯୁଗ୍ମ ସଂଖ୍ୟାଗୁଡ଼ିକ ହେବେ: x,x+2,x+4,…x, x+2, x+4, \dots

  • ଦୁଇ ଅଙ୍କ ବିଶିଷ୍ଟ ସଂଖ୍ୟା (Two-Digit Number): ଯଦି ଦଶକ ସ୍ଥାନୀୟ ଅଙ୍କ xx ଏବଂ ଏକକ ସ୍ଥାନୀୟ ଅଙ୍କ yy ହୁଏ, ତେବେ ମୂଳ ସଂଖ୍ୟାଟି ହେବ: 10x+y10x + y

  • ଅଙ୍କ ସ୍ଥାନ ବଦଳାଇଲେ (Reversing the Digits): ନୂତନ ସଂଖ୍ୟାଟି ହେବ: 10y+x10y + x

  • ବ୍ୟୁତ୍‌କ୍ରମ (Reciprocal): ଯଦି ସଂଖ୍ୟାଟି xx ହୁଏ, ତାହାର ବ୍ୟୁତ୍‌କ୍ରମ ହେବ: 1x\frac{1}{x}

⏳ ୨. ଦୂରତା, ସମୟ ଏବଂ ବେଗ (Distance, Time, and Speed):

  • ଦୂରତା (Distance): ଦୂରତା = ବେଗ ×\times ସମୟ (D=S×TD = S \times T)

  • ସମୟ (Time): ସମୟ = ଦୂରତା / ବେଗ (T=DST = \frac{D}{S})

  • ବେଗ (Speed): ବେଗ = ଦୂରତା / ସମୟ (S=DTS = \frac{D}{T})

  • ନୌକା ଓ ସ୍ରୋତ (Boat and Stream): ମନେକର ସ୍ଥିର ଜଳରେ ନୌକାର ବେଗ xx କି.ମି./ଘଣ୍ଟା ଏବଂ ସ୍ରୋତର ବେଗ yy କି.ମି./ଘଣ୍ଟା।

  • ସ୍ରୋତର ଅନୁକୂଳରେ ବେଗ (Downstream Speed) = x+yx + y

  • ସ୍ରୋତର ପ୍ରତିକୂଳରେ ବେଗ (Upstream Speed) = x−yx - y

📐 ୩. ଜ୍ୟାମିତିକ ସୂତ୍ର (Geometric Formulas):

  • ଆୟତକ୍ଷେତ୍ର (Rectangle):

  • କ୍ଷେତ୍ରଫଳ (Area) = ଦୈର୍ଘ୍ୟ ×\times ପ୍ରସ୍ଥ (A=l×bA = l \times b)

  • ପରିସୀମା (Perimeter) = ଦୈର୍ଘ୍ୟପ୍ରସ୍ଥ2×(ଦୈର୍ଘ୍ୟ+ପ୍ରସ୍ଥ)2 \times (\text{ଦୈର୍ଘ୍ୟ} + \text{ପ୍ରସ୍ଥ}) ଅର୍ଥାତ୍ P=2(l+b)P = 2(l + b)

  • ସମକୋଣୀ ତ୍ରିଭୁଜ (Right-angled Triangle):

  • କ୍ଷେତ୍ରଫଳ (Area) = ଭୂମିଉଚ୍ଚତା12×ଭୂମି×ଉଚ୍ଚତା\frac{1}{2} \times \text{ଭୂମି} \times \text{ଉଚ୍ଚତା} (A=12×b×pA = \frac{1}{2} \times b \times p)

  • ପିଥାଗୋରାସ୍ ଉପପାଦ୍ୟ (Pythagorean Theorem): କର୍ଣ୍ଣ2^2 = ଭୂମି2^2 + ଉଚ୍ଚତା2^2 (h2=p2+b2)(h^2 = p^2 + b^2)

  • ବର୍ଗକ୍ଷେତ୍ର (Square):

  • କ୍ଷେତ୍ରଫଳ (Area) = ବାହୁ ×\times ବାହୁ (A=a2A = a^2)

👨‍🔧 ୪. କାର୍ଯ୍ୟ ଓ ସମୟ (Work and Time):

  • ଯଦି ଜଣେ ବ୍ୟକ୍ତି ଗୋଟିଏ କାର୍ଯ୍ୟକୁ xx ଦିନରେ ଶେଷ କରେ, ତେବେ:
  • ୧ ଦିନରେ ସେ କାର୍ଯ୍ୟର ମୋଟ ଅଂଶ କରିବ = 1x\frac{1}{x}

👴 ୫. ବୟସ ସମ୍ବନ୍ଧୀୟ (Age Problems):

  • ଯଦି ଜଣକର ବର୍ତ୍ତମାନ ବୟସ xx ବର୍ଷ ହୁଏ, ତେବେ:

  • nn ବର୍ଷ ପରେ (After) ବୟସ ହେବ = x+nx + n

  • nn ବର୍ଷ ପୂର୍ବେ (Before) ବୟସ ଥିଲା = x−nx -

୨.୮ ପାଟୀଗାଣିତିକ ପ୍ରଶ୍ନର ସମାଧାନରେ ପ୍ରୟୋଗ (Application in solving Word Problems) 🌟

ଦୈନନ୍ଦିନ ଜୀବନରେ ଏବଂ ବିଭିନ୍ନ ଗାଣିତିକ ସମସ୍ୟାରେ (ଯଥା: ସଂଖ୍ୟା, ବୟସ, ସମୟ-ଦୂରତା, ଏବଂ କ୍ଷେତ୍ରଫଳ ସମ୍ବନ୍ଧୀୟ) ଆମେ ଦ୍ବିଘାତ ସମୀକରଣର ପ୍ରୟୋଗ କରିଥାଉ। ଏହି ପ୍ରଶ୍ନଗୁଡ଼ିକର ସମାଧାନ ପାଇଁ ନିମ୍ନଲିଖିତ ପଦକ୍ଷେପଗୁଡ଼ିକୁ ଅନୁସରଣ କରାଯାଏ:

ପ୍ରଥମେ ପ୍ରଶ୍ନଟିକୁ ଭଲଭାବରେ ପଢ଼ି ଅଜ୍ଞାତ ରାଶିକୁ xx (କିମ୍ବା ଅନ୍ୟ କୌଣସି ଚଳରାଶି) ରୂପେ ଗ୍ରହଣ କରାଯାଏ। ତା'ପରେ ପ୍ରଶ୍ନରେ ଦିଆଯାଇଥିବା ସର୍ତ୍ତ ଅନୁଯାୟୀ ଏକ ଦ୍ବିଘାତ ସମୀକରଣ ଗଠନ କରାଯାଏ (ଯଥା: ax2+bx+c=0ax^2 + bx + c = 0)। ଶେଷରେ ଉତ୍ପାଦକୀକରଣ (Factorization) କିମ୍ବା ଦ୍ବିଘାତ ସୂତ୍ର (Quadratic Formula) ପ୍ରୟୋଗ କରି xx ର ମୂଲ୍ୟ ବାହାର କରାଯାଏ। ମିଳିଥିବା ମୂଳଗୁଡ଼ିକ ମଧ୍ୟରୁ ଯେଉଁଟି ବାସ୍ତବ କ୍ଷେତ୍ରରେ ଅସମ୍ଭବ (ଯଥା ବୟସ କିମ୍ବା ଦୂରତା ଋଣାତ୍ମକ ହେବା), ତାହାକୁ ବାଦ୍ ଦେଇ ସଠିକ୍ ମୂଲ୍ୟଟିକୁ ଉତ୍ତର ରୂପେ ଗ୍ରହଣ କରାଯାଏ।

📝 ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ଉଦାହରଣ (Important Examples)

ଉଦାହରଣ ୧: (ସଂଖ୍ୟା ସମ୍ବନ୍ଧୀୟ) ଗୋଟିଏ ସଂଖ୍ୟା ଓ ତାହାର ବ୍ୟୁତ୍‌କ୍ରମ (reciprocal) ର ସମଷ୍ଟି 52\frac{5}{2} ହେଲେ, ସଂଖ୍ୟାଟି ନିର୍ଣ୍ଣୟ କର।

✏️ ସମାଧାନ: ମନେକର ସଂଖ୍ୟାଟି ହେଉଛି xx। ତେଣୁ ଏହାର ବ୍ୟୁତ୍‌କ୍ରମ ହେବ 1x\frac{1}{x}। ପ୍ରଶ୍ନ ଅନୁଯାୟୀ:

x+1x=52x + \frac{1}{x} = \frac{5}{2}

ଏହାକୁ ସରଳ କଲେ:

x2+1x=52⇒2(x2+1)=5x⇒2x2−5x+2=0\frac{x^2 + 1}{x} = \frac{5}{2} \Rightarrow 2(x^2 + 1) = 5x \Rightarrow 2x^2 - 5x + 2 = 0

ଏହି ଦ୍ବିଘାତ ସମୀକରଣକୁ ଉତ୍ପାଦକୀକରଣ କଲେ:

2x2−4x−x+2=0⇒2x(x−2)−1(x−2)=0⇒(2x−1)(x−2)=02x^2 - 4x - x + 2 = 0 \Rightarrow 2x(x - 2) - 1(x - 2) = 0 \Rightarrow (2x - 1)(x - 2) = 0

ତେଣୁ 2x−1=0⇒x=122x - 1 = 0 \Rightarrow x = \frac{1}{2} କିମ୍ବା x−2=0⇒x=2x - 2 = 0 \Rightarrow x = 2। ଉତ୍ତର: ନିର୍ଣ୍ଣେୟ ସଂଖ୍ୟାଟି 2 କିମ୍ବା 12\frac{1}{2} ଅଟେ। ✅

ଉଦାହରଣ ୨: (କ୍ରମିକ ସଂଖ୍ୟା ସମ୍ବନ୍ଧୀୟ) ଦୁଇଟି କ୍ରମିକ ଅଯୁଗ୍ମ ଧନାତ୍ମକ (consecutive odd positive) ସଂଖ୍ୟାର ଗୁଣଫଳ 143 ହେଲେ, ସଂଖ୍ୟା ଦ୍ଵୟ ନିର୍ଣ୍ଣୟ କର।

✏️ ସମାଧାନ: ମନେକର ଦୁଇଟି କ୍ରମିକ ଅଯୁଗ୍ମ ଧନାତ୍ମକ ସଂଖ୍ୟା ହେଉଛି xx ଏବଂ x+2x + 2। ପ୍ରଶ୍ନ ଅନୁଯାୟୀ ସେମାନଙ୍କର ଗୁଣଫଳ 143 ଅଟେ:

x(x+2)=143⇒x2+2x−143=0x(x + 2) = 143 \Rightarrow x^2 + 2x - 143 = 0

ଏହାକୁ ଉତ୍ପାଦକୀକରଣ କଲେ (143 କୁ ଭାଙ୍ଗିଲେ 13 ଓ 11 ମିଳିବ):

x2+13x−11x−143=0⇒x(x+13)−11(x+13)=0⇒(x+13)(x−11)=0x^2 + 13x - 11x - 143 = 0 \Rightarrow x(x + 13) - 11(x + 13) = 0 \Rightarrow (x + 13)(x - 11) = 0

ଏଥିରୁ ଆମେ ପାଇବା x=−13x = -13 କିମ୍ବା x=11x = 11। ଯେହେତୁ ସଂଖ୍ୟାଗୁଡ଼ିକ ଧନାତ୍ମକ ବୋଲି ପ୍ରଶ୍ନରେ ଦିଆଯାଇଛି, ଆମେ x=−13x = -13 କୁ ଗ୍ରହଣ କରିପାରିବା ନାହିଁ। ତେଣୁ x=11x = 11। ଅନ୍ୟ ସଂଖ୍ୟାଟି ହେବ x+2=11+2=13x + 2 = 11 + 2 = 13। ଉତ୍ତର: ନିର୍ଣ୍ଣେୟ ସଂଖ୍ୟା ଦ୍ଵୟ 11 ଏବଂ 13 ଅଟେ। ✅

ଉଦାହରଣ ୩: (କ୍ଷେତ୍ରଫଳ ସମ୍ବନ୍ଧୀୟ) ଗୋଟିଏ ଆୟତାକାର ପଡ଼ିଆର ଦୈର୍ଘ୍ୟ ଏହାର ପ୍ରସ୍ଥ ଠାରୁ 3 ମିଟର ଅଧିକ। ଯଦି ଏହାର କ୍ଷେତ୍ରଫଳ 108 ବର୍ଗ ମିଟର ହୁଏ, ତେବେ ପଡ଼ିଆର ଦୈର୍ଘ୍ୟ ଓ ପ୍ରସ୍ଥ ନିରୂପଣ କର।

✏️ ସମାଧାନ: ମନେକର ପଡ଼ିଆର ପ୍ରସ୍ଥ ହେଉଛି xx ମିଟର। ତେଣୁ ଏହାର ଦୈର୍ଘ୍ୟ ହେବ (x+3)(x + 3) ମିଟର। ଆୟତକ୍ଷେତ୍ରର କ୍ଷେତ୍ରଫଳ = ଦୈର୍ଘ୍ୟ ×\times ପ୍ରସ୍ଥ। ପ୍ରଶ୍ନ ଅନୁଯାୟୀ:

x(x+3)=108⇒x2+3x−108=0x(x + 3) = 108 \Rightarrow x^2 + 3x - 108 = 0

ଏହାକୁ ଉତ୍ପାଦକୀକରଣ କଲେ:

x2+12x−9x−108=0⇒x(x+12)−9(x+12)=0⇒(x+12)(x−9)=0x^2 + 12x - 9x - 108 = 0 \Rightarrow x(x + 12) - 9(x + 12) = 0 \Rightarrow (x + 12)(x - 9) = 0

ଏଥିରୁ ଆମେ ପାଇବା x=−12x = -12 କିମ୍ବା x=9x = 9। ଦୈର୍ଘ୍ୟ କିମ୍ବା ପ୍ରସ୍ଥ କେବେହେଲେ ଋଣାତ୍ମକ ହୋଇପାରିବ ନାହିଁ। ତେଣୁ x=−12x = -12 ଅସମ୍ଭବ ଅଟେ। ଅତଏବ ପ୍ରସ୍ଥ x=9x = 9 ମିଟର ଏବଂ ଦୈର୍ଘ୍ୟ x+3=9+3=12x + 3 = 9 + 3 = 12 ମିଟର ଅଟେ। ଉତ୍ତର: ଦୈର୍ଘ୍ୟ 12 ମିଟର ଓ ପ୍ରସ୍ଥ 9 ମିଟର। ✅

ଉଦାହରଣ ୪: (ଦୂରତା ଓ ସମୟ ସମ୍ବନ୍ଧୀୟ) ଗୋଟିଏ ଟ୍ରେନ୍ ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ ବେଗରେ 360 କି.ମି. ଦୂରତା ଅତିକ୍ରମ କରେ। ଯଦି ଏହାର ବେଗ ଘଣ୍ଟାପ୍ରତି 5 କି.ମି. ଅଧିକ ହୋଇଥାନ୍ତା, ତେବେ ସେହି ଦୂରତା ଅତିକ୍ରମ କରିବା ପାଇଁ ଏହାକୁ 1 ଘଣ୍ଟା କମ୍ ସମୟ ଲାଗିଥାନ୍ତା। ଟ୍ରେନ୍‌ଟିର ମୂଳ ବେଗ ନିର୍ଣ୍ଣୟ କର।

✏️ ସମାଧାନ: ମନେକର ଟ୍ରେନ୍‌ଟିର ମୂଳ ବେଗ ଘଣ୍ଟାପ୍ରତି xx କି.ମି. ଅଟେ। 360 କି.ମି. ଅତିକ୍ରମ କରିବାକୁ ଆବଶ୍ୟକ ସମୟ =360x= \frac{360}{x} ଘଣ୍ଟା। ଯଦି ବେଗ ଘଣ୍ଟାପ୍ରତି (x+5)(x + 5) କି.ମି. ହୁଏ, ତେବେ ଆବଶ୍ୟକ ସମୟ =360x+5= \frac{360}{x + 5} ଘଣ୍ଟା। ପ୍ରଶ୍ନ ଅନୁଯାୟୀ, ନୂଆ ସମୟ ମୂଳ ସମୟ ଠାରୁ 1 ଘଣ୍ଟା କମ୍ ଅଟେ:

360x−360x+5=1\frac{360}{x} - \frac{360}{x + 5} = 1

ଏହାକୁ ସରଳ କଲେ:

360(x+5)−360xx(x+5)=1⇒360x+1800−360xx2+5x=1⇒1800x2+5x=1\frac{360(x + 5) - 360x}{x(x + 5)} = 1 \Rightarrow \frac{360x + 1800 - 360x}{x^2 + 5x} = 1 \Rightarrow \frac{1800}{x^2 + 5x} = 1

ବଜ୍ରଗୁଣନ ଦ୍ୱାରା:

x2+5x=1800⇒x2+5x−1800=0x^2 + 5x = 1800 \Rightarrow x^2 + 5x - 1800 = 0

ଏହାକୁ ଉତ୍ପାଦକୀକରଣ କଲେ:

x2+45x−40x−1800=0⇒x(x+45)−40(x+45)=0⇒(x+45)(x−40)=0x^2 + 45x - 40x - 1800 = 0 \Rightarrow x(x + 45) - 40(x + 45) = 0 \Rightarrow (x + 45)(x - 40) = 0

ଏଥିରୁ ମିଳିବ x=−45x = -45 କିମ୍ବା x=40x = 40। ଟ୍ରେନ୍‌ର ବେଗ ଋଣାତ୍ମକ ହୋଇନପାରେ, ତେଣୁ x=40x = 40। ଉତ୍ତର: ଟ୍ରେନ୍‌ଟିର ମୂଳ ବେଗ ଘଣ୍ଟାପ୍ରତି 40 କି.ମି. ଅଟେ। ✅
