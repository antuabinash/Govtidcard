ରେଖା ଓ କୋଣ ମୂଲ୍ୟାୟନ ପ୍ରଶ୍ନବଳୀ (ପୃଷ୍ଠା ୨୯-୩୧ ଉପରେ ଆଧାରିତ)

 

ବିଭାଗ କ: ଶୂନ୍ୟସ୍ଥାନ ପୂରଣ କର (ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନ 1 ମାର୍କ)

  1. ଗୋଟିଏ ସରଳକୋଣରେ ସମୁଦାୟ ________ ଟି ସମକୋଣ ରହିଥାଏ।

  2. ସମକୋଣରେ ମିଶିଥିବା ଦୁଇଟି ସରଳରେଖାକୁ ପରସ୍ପର ପ୍ରତି ________ ରେଖା କୁହାଯାଏ।

  3. ଏକ ସମକୋଣଠାରୁ କମ୍ ପରିମାଣ ବା 1/4 ମୋଡ଼ରୁ କମ୍ ବିଶିଷ୍ଟ କୋଣକୁ ________ କୁହାଯାଏ।

  4. ଗୋଟିଏ ସମକୋଣଠାରୁ ବଡ଼ କିନ୍ତୁ ସରଳକୋଣଠାରୁ କମ୍ କୋଣକୁ ________ କୁହାଯାଏ।

  5. ସାଧାରଣତଃ ଗୋଟିଏ ସମକୋଣ ଇଂରାଜୀ ବଡ଼ ଅକ୍ଷର ________ ଆକୃତି ସହିତ ସମାନ ହୋଇଥାଏ।

  6. ସଂପୂର୍ଣ୍ଣ ଘୂର୍ଣ୍ଣନର ଠିକ୍ ଅଧା ଭାଗ (1/2 ମୋଡ଼) ଦ୍ୱାରା ଗୋଟିଏ ________ କୋଣ ଗଠିତ ହୁଏ।

  7. ସଂପୂର୍ଣ୍ଣ ଘୂର୍ଣ୍ଣନର ଏକ ଚତୁର୍ଥାଂଶ (1/4 ମୋଡ଼) ଦ୍ୱାରା ଗୋଟିଏ ________ କୋଣ ଗଠିତ ହୁଏ।

  8. ବହିର ମଲାଟକୁ ସମ୍ପୂର୍ଣ୍ଣ ଓଲଟାଇ ଦେଲେ ବା ଟେବୁଲ ଉପରେ ମେଲାଇ ରଖିଲେ ସେଥିରେ ________ କୋଣ ସୃଷ୍ଟି ହୁଏ।

  9. ଏକ ସରଳକୋଣକୁ ଠିକ୍ ସମାନ ଦୁଇ ଭାଗରେ ବିଭକ୍ତ କଲେ ପ୍ରତ୍ୟେକ ଭାଗ ଗୋଟିଏ ଲେଖାଏଁ ________ ହୋଇଥାଏ।

  10. କାଗଜରେ ଥିବା ଏକ ତେରେଚ୍ଛା ଗାର ଉପରେ ଆଉ ଗୋଟିଏ ଲମ୍ବ ଗାର ଟାଣିଲେ ସେଠାରେ ________ କୋଣ ଉତ୍ପନ୍ନ ହୁଏ।

12. ଗୋଟିଏ ସରଳକୋଣର ପରିମାଣ ଦୁଇଟି ସମକୋଣର ସମଷ୍ଟି ସହ ସମାନ। ( ସତ୍ୟ / ମିଥ୍ୟା )

13. ସ୍ଥୂଳକୋଣର ପରିମାଣ ସର୍ବଦା ଏକ ଚତୁର୍ଥାଂଶ ମୋଡ଼ (1/4) ଠାରୁ କମ୍ ହୋଇଥାଏ। ( ସତ୍ୟ / ମିଥ୍ୟା )

14. 'L' ଆକାରରେ ଗଠିତ କୋଣଟି ଏକ ସୂକ୍ଷ୍ମକୋଣର ଦୃଷ୍ଟାନ୍ତ ଅଟେ। ( ସତ୍ୟ / ମିଥ୍ୟା )

15. ଟେବୁଲ୍ ଉପରେ ବହିକୁ ଅଧା ଖୋଲିଦେଲେ ମଲାଟ ଦ୍ୱାରା ସାଧାରଣତଃ ଏକ ସୂକ୍ଷ୍ମକୋଣ ବା ସ୍ଥୂଳକୋଣ ଗଠିତ ହୋଇପାରେ। ( ସତ୍ୟ / ମିଥ୍ୟା )

17. ସମସ୍ତ ସୂକ୍ଷ୍ମକୋଣର ଘୂର୍ଣ୍ଣନ ପରିମାଣ ସମକୋଣଠାରୁ କମ୍ ଅଟେ। ( ସତ୍ୟ / ମିଥ୍ୟା )

18. ବିନ୍ଦୁ ଗ୍ରିଡ୍ (Dot grid) ବ୍ୟବହାର କରି କେବଳ ସରଳକୋଣ ଅଙ୍କନ କରାଯାଇପାରିବ, ସମକୋଣ ନୁହେଁ। ( ସତ୍ୟ / ମିଥ୍ୟା )

19. ଗୋଟିଏ କୋଣ ସମକୋଣ ହେବ, ଯଦି ଏହା ଗୋଟିଏ ସରଳ କୋଣର ଅଧା ହୋଇଥିବ। ( ସତ୍ୟ / ମିଥ୍ୟା )

20. କୋଣମାନଙ୍କର ବର୍ଗୀକରଣ କେବଳ ବାହୁଗୁଡ଼ିକର ଦୈର୍ଘ୍ୟ ଉପରେ ନିର୍ଭର କରେ। ( ସତ୍ୟ / ମିଥ୍ୟା )

39. 'ଏକ ଚତୁର୍ଥାଂଶ ମୋଡ଼' (1/4 turn) ଏବଂ 'ଅଧା ମୋଡ଼' (1/2 turn) ମଧ୍ୟରେ ଥିବା ପାର୍ଥକ୍ୟ କ'ଣ?

40. ତୁମେ କିପରି ବୁଝାଇବ ଯେ 'L' ଆକୃତିରୁ କମ୍ ଖୋଲା ଥିବା କୋଣଟି ଏକ ସୂକ୍ଷ୍ମକୋଣ ଅଟେ?

ବିଭାଗ ଙ: ଦୀର୍ଘ ଉତ୍ତରମୂଳକ ଓ ପ୍ରୟୋଗାତ୍ମକ ପ୍ରଶ୍ନ (3 ରୁ 5 ମାର୍କ)

41. (କ) ଘୂର୍ଣ୍ଣନର ପରିମାଣ ଉପରେ ଭିତ୍ତି କରି କୋଣମାନଙ୍କର ତିନୋଟି ମୁଖ୍ୟ ବର୍ଗୀକରଣ (ସୂକ୍ଷ୍ମ, ସମ, ସ୍ଥୂଳ) ର ସଂଜ୍ଞା ଲେଖ। (ଖ) ଶ୍ରେଣୀଗୃହ ବା ନିଜ ଘରର ଯେକୌଣସି ବସ୍ତୁକୁ ଦେଖି ଗୋଟିଏ ଲେଖାଏଁ ଉଦାହରଣ ଦିଅ।

42. "ଗୋଟିଏ କୋଣ ସମକୋଣ ହୁଏ, ଯଦି ଏହା ଗୋଟିଏ ସରଳ କୋଣର ଅଧା ହୋଇଥିବ।" - କାଗଜ ଭାଙ୍ଗିବା ପ୍ରଣାଳୀ (Paper folding method) ବ୍ୟବହାର କରି ଏହି ଉକ୍ତିଟିକୁ କିପରି ପ୍ରମାଣିତ କରିବ ତାହାର ପଦକ୍ଷେପଗୁଡ଼ିକୁ ଧାଡ଼ି କରି ଲେଖ।

43. ବିନ୍ଦୁ ଗ୍ରିଡ୍ (Dot Grid) ସାହାଯ୍ୟରେ ଗୋଟିଏ ସରଳକୋଣ ∠CAB ଅଙ୍କନ କର। ବର୍ତ୍ତମାନ A ବିନ୍ଦୁଠାରେ ଏପରି ଏକ ନୂତନ ରେଖାଖଣ୍ଡ ଅଙ୍କନ କରିବାର ପ୍ରଣାଳୀ ବର୍ଣ୍ଣନା କର, ଯାହା ଫଳରେ ସେଠାରେ ଦୁଇଟି ସମକୋଣ ସୃଷ୍ଟି ହେବ।

44. "କୋଣମାନଙ୍କର ବର୍ଗୀକରଣ ମୁଖ୍ୟତଃ ମୋଡ଼ (Turn) ର ପରିମାଣ ଉପରେ ନିର୍ଭର କରେ, ବାହୁର ଦୈର୍ଘ୍ୟ ଉପରେ ନୁହେଁ।" - ଏହି କଥାଟିକୁ ଏକ ଉଦାହରଣ ମାଧ୍ୟମରେ ସବିଶେଷ ବ୍ୟାଖ୍ୟା କର।

45. କାଗଜରେ ଗୋଟିଏ ତେରେଚ୍ଛା (Slanting) ଗାର ଟାଣ। ସେହି ଗାର ଉପରେ ଆଉ ଏକ ଗାର ଏପରି ଆଙ୍କ ଯେପରି ତାହା ପ୍ରଥମ ଗାର ଉପରେ ସମ୍ପୂର୍ଣ୍ଣ ଲମ୍ବ (Perpendicular) ହେବ। (କ) ଏହାଦ୍ୱାରା ଛେଦ ବିନ୍ଦୁଠାରେ ମୋଟ କେତୋଟି କୋଣ ସୃଷ୍ଟି ହେଲା? (ଖ) ସେହି କୋଣଗୁଡ଼ିକ କେଉଁ ପ୍ରକାରର କୋଣ ଅଟନ୍ତି ଏବଂ ତାହା ତୁମେ କିପରି ପ୍ରମାଣ କରିବ?
